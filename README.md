## Unravel Editorial

Website for fiction and nonfiction editorial services provider.

[![LIVE SITE](https://img.shields.io/badge/LIVE_SITE-4ECCA3?style=for-the-badge&logo=astro&logoColor=black)](https://unraveleditorial.com/) &nbsp;


## Getting started

Run the site locally with the same commands used for typical Astro projects:

| Command           | Action                                       |
| :---------------- | :------------------------------------------- |
| `npm install`     | Installs dependencies                        |
| `npm run dev`     | Starts local dev server at `localhost:4321`  |
| `npm run build`   | Build your production site to `./dist/`      |
| `npm run preview` | Preview your build locally, before deploying |
